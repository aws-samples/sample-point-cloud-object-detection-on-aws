# Security

## Reporting a vulnerability

If you discover a potential security issue in this project, notify AWS/Amazon Security
through the [vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/).
Please do **not** open a public GitHub issue.

## Scope

This is sample code for non-production use. The README's [Security](README.md#security)
section lists what you must review before deploying it, and
[docs/security/THREAT_MODEL.md](docs/security/THREAT_MODEL.md) records its threat model,
the controls it implements and the risks it leaves to you.
